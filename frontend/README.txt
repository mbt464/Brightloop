BRIGHTLOOP REACT HOMEPAGE

These files are intended for your EXISTING Vite React project.
Do not replace the entire frontend folder or any package files.

Copy:
  src/App.jsx     -> SubscriptionManagementSystem/frontend/src/App.jsx
  src/App.css     -> SubscriptionManagementSystem/frontend/src/App.css
  src/index.css   -> SubscriptionManagementSystem/frontend/src/index.css
  index.html      -> SubscriptionManagementSystem/frontend/index.html

The existing frontend/src/main.jsx from Vite stays unchanged.

Run from SubscriptionManagementSystem/frontend:
  npm run dev

Open the local URL printed by Vite (usually http://localhost:5173/).
The buttons are currently navigation anchors and the example dashboard numbers are illustrative only.
Backend functionality will be connected in later steps.
